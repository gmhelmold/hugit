# Security Policy

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately by emailing the maintainers directly. Include
a description of the issue, steps to reproduce, and the potential impact. You
will receive an acknowledgement within 48 hours.

We follow responsible disclosure: we ask that you give us reasonable time to
investigate and ship a fix before public disclosure.

## Scope

This policy covers the `hugit` engine, CLI, and HTTP API. Vulnerabilities in
third-party dependencies should be reported to the respective upstream projects.
