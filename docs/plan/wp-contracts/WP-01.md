## Charter
Turn `hugit` into a Rust workspace (the house stack) with the 12 crates the
warp plan names, wire the four CI gates (fmt/clippy/test/audit) green on the
empty scaffold, and configure DCO + changelog discipline. This is the chassis
every other WP builds inside; it must compile and pass all gates with zero
business logic.

## Implementation notes
Every fork pre-decided:
- **Workspace layout:** virtual workspace root `Cargo.toml` with
  `[workspace] members = ["crates/*"]`; resolver = "2".
- **Crate set:** the 12 named above, verbatim from warp §Day-0; each is a
  `lib` crate with a single empty `src/lib.rs` (`//! <crate> — scaffold` doc
  comment, no items) so clippy/test pass with nothing to lint.
- **`hugit-app`** targets a Cloudflare Worker (warp + whitepaper L4) — scaffold
  only declares the crate; the Worker entrypoint is B1's claim, not here.
- **Toolchain:** pin via `rust-toolchain.toml` (channel matching the repo's
  established toolchain); `.cargo/config.toml` sets `CARGO_BUILD_JOBS = 4`
  (CLAUDE.md runner-protection rule).
- **CI gates:** one `ci.yml` running, in order, `fmt --check` → `clippy
  -D warnings` → `test` → `audit`; `dco.yml` enforces `Signed-off-by:`; the
  changelog gate is a script that fails `feat:`/`fix:` PRs lacking an
  `[Unreleased]` entry.
- **No business logic anywhere** — every gate is green precisely because the
  tree is empty; downstream WPs fill the crates.
