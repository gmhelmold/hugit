# HUG-008 — Coordenação nativa com coexistência controlada de versões

**Estado:** planned; **owner:** B; **fase:** B; **prioridade:** first_slice.

**Dependências:** HUG-003

**Congelamento de runtime requerido:** false

**Revisões:** AR-01, AR-15

## Prontidão

Todos os predecessores possuem evidência integrada e interfaces versionadas compatíveis.

Owner B aceita write-set exato e budget B-CORE; HUG-001 distingue arquivos existentes dos novos.

Os casos P/N/Q/R e os oráculos estão especificados antes do dispatch; fixtures e testes executáveis são entregues pelo próprio pacote ou predecessor. Documentação/descoberta usa oráculos de artefato, não um falso bug de runtime.

Qualquer dado de fonte ainda não observado bloqueia o consumidor; descobrir no pacote predecessor, sem inventar payload.

Usar a especificação aprovada desta revisão; descobertas/contratos e contenções de baseline produzem as pré-condições do freeze, sem ativar implicitamente o runtime v2.

## Unidades verificáveis

1. **HUG-008.S1** — Implementar lock estável do SO em arquivo que nunca é unlinkado por release; handles não herdáveis por subprocessos.
2. **HUG-008.S2** — Manter v2 experimental em diretório separado; não trocar unilateralmente o protocolo de produção v1 antes de HUG-058/018.
3. **HUG-008.S3** — Definir ordem de locks installation-budget→repo-admission→operation; DB transaction não fica aberta ao esperar I/O/lock externo.

## Budget e recuperação

P11: read default 8 KiB, page 64 KiB, request 1 MiB; DB/transações/filas bounded; admission antes de novos bytes.

**Rollback/recovery:** Desativar novo writer antes de voltar a protocolo anterior; só restaurar escritor v1 em runtime não migrado após quiescência. Store v2 continua read-only recuperável se um target não suportar locking correto.

**Rollout:** habilitar só depois das assertions, qualificação de célula e revisão. Flag não anuncia recurso não qualificado.

**Plano de evidências:** pacote B/C destacado do sujeito imutável A; não commitar resultados em A para exigir seu próprio hash.
