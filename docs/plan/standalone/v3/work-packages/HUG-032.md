## Unidades verificáveis

1. **HUG-032.S1** — Manifesto usa tipos file/directory/symlink, bytes de path codificados sem normalização silenciosa e modes limitados; occurrence carrega nome e produtor.
2. **HUG-032.S2** — Preservar somente outputs finalizados de área de run ou import explícito; cópia de arquivo concorrente marcada mixed/partial quando não há garantia de produtor estável.
3. **HUG-032.S3** — Restore detecta case collisions, Unicode/reserved names e reparse; nunca segue symlink fora de root nem preserva setuid/devices por default.

## Budget e recuperação

P02/P11: streaming bounded, allocation em chunks, espaço transitório reservado; digest/tamanho verificados; max expansion segue budget local e não tamanho declarado pelo arquivo.

**Rollback/recovery:** Cancelar materialização temporária por ownership e deixar destino existente intacto; versões inválidas de manifest são quarantine metadata. Não alterar blobs canônicos para corrigir nome incompatível: oferecer mapping explícito novo.

**Rollout:** habilitar só depois das assertions, qualificação de célula e revisão. Flag não anuncia recurso não qualificado.

**Plano de evidências:** pacote B/C destacado do sujeito imutável A; não commitar resultados em A para exigir seu próprio hash.
